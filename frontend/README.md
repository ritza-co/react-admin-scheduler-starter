# `ra-tree` Simple Example

This is a simple example showcasing the [`ra-tree`](https://marmelab.com/ra-enterprise/modules/ra-tree) package of [react-admin](https://github.com/marmelab/react-admin).

## Prerequisites

This project uses packages from the [Enterprise Edition of react-admin](https://marmelab.com/ra-enterprise). To be able to download them, you need to have a running subscription, and to have configured your package manager to use the private registry. Insctructions can be found at https://registry.marmelab.com/setup.

## How to run

Run the following commands at the root of the project:

```sh
yarn
yarn dev
```

Or, with `npm`:

```sh
npm install
npm run dev
```
